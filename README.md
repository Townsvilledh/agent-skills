# Agent Skills by Ethuram

Skills for AI agents, written and battle-tested by **Ethuram (Townsvilledh)** — maker of
[Fluid Wallet](https://fluidwallet.dpdns.org) and
[token-launch-radar](https://github.com/Townsvilledh/token-launch-radar). Every skill
here exists because a real failure taught the lesson it encodes. No filler packs, no
repackaged free skills.

## The catalogue

### 1. Token Launch Radar — $29 (one-time, suggested launch price)

Ranks pre-token DeFi protocols by implied value — priced from the live-token peers in
each protocol's own category — and writes a farm plan for each. Deterministic, runs
offline on a DefiLlama snapshot you supply, Node 22 standard library only.

- Full skill text: [`token-launch-radar/SKILL.md`](token-launch-radar/SKILL.md)
- Underlying project (MIT): https://github.com/Townsvilledh/token-launch-radar

### 2. DeFi Agent Safety Pack — $19 (one-time, suggested launch price)

Three playbooks that keep an agent honest when it touches DeFi money: disclose fees by
component and reconcile them against the quote; reconcile wallet balances on-chain
before reporting them; verify who actually settles a contract route before calling it
permissionless.

- Details: [`defi-agent-safety-pack/README.md`](defi-agent-safety-pack/README.md)

### 3. Agent Work Verification Pack — $15 (one-time, suggested launch price)

Two playbooks for anyone who delegates to agents: verify delegated build claims against
independent ground truth before repeating them, and prove scheduled work completed by
what it changed — not by its exit code.

- Details: [`agent-work-verification-pack/README.md`](agent-work-verification-pack/README.md)
